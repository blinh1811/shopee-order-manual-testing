# [BUG_003] SPayLater installment tenure dropdown becomes unclickable upon rotating mobile screen to landscape

- **Project**: Shopee Order & Checkout Flow
- **Reported By**: QA / Fresher Tester
- **Date Reported**: 2026-09-07
- **Environment**: 
  - Platform: Android Mobile Web & iOS Safari
  - Device: iPhone 13 / Samsung Galaxy S23
  - App Build: `v3.14.0-rc3`
- **Severity**: **Minor**
- **Priority**: **Low (P3)**
- **Status**: **Open**
- **Associated Test Case**: [`TC_49`](../test-cases/Test_Cases_Specification.md)
- **Component**: `Checkout > Payment Details > SPayLater`

---

### Description
When selecting "SPayLater" as the payment method on a mobile browser or tablet in landscape mode, the fixed footer navigation bar (`.checkout-action-footer`) overlaps with the bottom of the installment plan selection dropdown (e.g., 6-month and 12-month installment cards). As a result, the tap target is blocked by the z-index overlay and users cannot select longer tenure options without switching back to portrait orientation.

---

### Preconditions
1. User has an activated SPayLater credit line with an available limit exceeding the order subtotal.
2. Device orientation lock is disabled.
3. User is on the Checkout page in landscape mode ($844 \times 390\text{ px}$).

---

### Steps to Reproduce
1. On Checkout page, scroll down to **Payment Method**.
2. Select **SPayLater**.
3. Rotate the device from Portrait to Landscape orientation.
4. Attempt to click on the **12 Months (12 kỳ)** installment radio button at the bottom of the list.
5. Observe touch responsiveness.

---

### Expected Result
1. The installment options list should have appropriate bottom padding (`padding-bottom: 80px`).
2. The user can easily scroll down and tap any installment tenure card (1X, 3X, 6X, 12X).

---

### Actual Result
- The fixed "Place Order" bottom sticky bar covers the bottom 65px of the scroll container.
- The 12-month installment option cannot receive click events because the floating button captures all touches.

---

### Suggested Fix
In `PaymentMethodSelection.css`:
```css
@media (orientation: landscape) and (max-height: 500px) {
  .payment-options-container {
    padding-bottom: 90px; /* Prevent sticky footer overlap */
  }
}
```

---

### Impact & Workaround
- **User Impact**: Minor disruption for tablet and landscape mobile users.
- **Workaround**: User simply rotates their phone back to Portrait orientation to select the 12-month tenure.
