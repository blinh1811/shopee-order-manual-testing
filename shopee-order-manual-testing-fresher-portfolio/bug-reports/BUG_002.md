# [BUG_002] Voucher minimum-spend error tooltip renders unformatted raw string placeholder "{0} VND"

- **Project**: Shopee Order & Checkout Flow
- **Reported By**: QA / Fresher Tester
- **Date Reported**: 2026-09-07
- **Environment**: 
  - Platform: Mobile Web & Android App
  - Device: Xiaomi Redmi Note 12 / Chrome Mobile v128.0
  - App Build: `v3.14.0-rc3`
- **Severity**: **Major**
- **Priority**: **Medium (P2)**
- **Status**: **In Progress**
- **Associated Test Case**: [`TC_34`](../test-cases/Test_Cases_Specification.md)
- **Component**: `Checkout > Voucher & Promotion Engine`

---

### Description
When a user attempts to select an unavailable Shop Voucher whose minimum spend condition has not been met, the informational tooltip renders an unparsed i18n interpolation placeholder string:  
*`"Mua thêm {0} VND để sử dụng mã giảm giá này"`*  
instead of computing and displaying the actual remaining amount needed (e.g. *"Mua thêm 45.000đ để sử dụng mã giảm giá này"*).

---

### Preconditions
1. User cart has items from Seller "TechStore Official" totaling `205,000 VND`.
2. Seller offers a Voucher: *"Giảm 30K cho đơn từ 250,000 VND"*.
3. User progresses to the Checkout page and opens the **Shopee / Shop Voucher Selection Sheet**.

---

### Steps to Reproduce
1. In the Voucher selection sheet, locate the coupon *"Giảm 30K đơn từ 250K"*.
2. Note that the radio button is disabled (greyed out).
3. Tap on the coupon card or the info tooltip icon next to the voucher.
4. Read the displayed helper text in the modal banner.

---

### Expected Result
1. The dynamic calculation takes $250,000 - 205,000 = 45,000\text{ VND}$.
2. Tooltip renders:  
   *`"Mua thêm 45.000₫ từ shop để áp dụng mã giảm giá này."`*

---

### Actual Result
- The tooltip renders:  
  *`"Mua thêm {0} VND từ shop để áp dụng mã giảm giá này."`*
- The parameter interpolation failed in the localized string bundle `voucher_min_spend_warning`.

---

### Code Analysis / Root Cause
In `VoucherItemCard.tsx`:
```javascript
// Current faulty line:
const message = t('voucher_min_spend_warning'); // Missing parameter mapping!

// Expected fix:
const remainingAmount = formatCurrency(voucher.minSpend - currentSubtotal);
const message = t('voucher_min_spend_warning', { 0: remainingAmount });
```

---

### Impact & Workaround
- **User Impact**: Users cannot tell how much more they need to buy to qualify for the promotion, degrading UX and reducing potential basket upselling.
- **Workaround**: Users have to manually calculate the difference between the voucher's minimum threshold and their current cart total.
